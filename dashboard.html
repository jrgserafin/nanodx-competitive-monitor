What runs: every weekday morning a GitHub Action sweeps Google News, competitor web pages, RSS feeds, FDA 510(k)/PMA decisions, ClinicalTrials.gov and PubMed for each target in competitors.yaml. New items land here and go out as an email digest.

Look something up now: Run a lookup → Run workflow. Leave “only” blank for everyone or type a name (e.g. Abbott); tick “send email” to mail the result. The console refreshes about 2 minutes after the run finishes.

Add a competitor: Edit targets, copy an existing block, change the name and searches, commit.

High-signal items mention keywords like FDA, clearance, launch, acquisition, CLIA or reimbursement (editable in competitors.yaml).

Shortcuts: / search · Esc clear.

Only headlines and short snippets from public sources are stored; follow links for full content.
