What runs: every weekday morning a GitHub Action sweeps Google News, competitor web pages, RSS feeds, FDA 510(k)/PMA decisions, ClinicalTrials.gov, PubMed, SEC filings, US patents, job boards and the Federal Register for each target in competitors.yaml. New items land here and go out as an email digest; three more sweeps during the day send instant alerts for FDA decisions, deals, launches and similar. Mondays add a weekly review and refresh the battlecards.

AI analyst: when the ANTHROPIC_API_KEY secret is set, digests, alerts and the weekly review open with a written brief, and each battlecard gets a summary, threat level and talk track. Describe NanoDx in company_context so the analysis is relevant.

Battlecards: one page per competitor — FDA record, recent moves, SEC filings, trials, publications, patents, hiring, plus your team's notes from the profile block. Use Print / PDF to share one, or ⇩ CSV to export.

Look something up now: Run a lookup → Run workflow. Pick a mode (digest, alerts, weekly or collect), leave “only” blank for everyone or type a name (e.g. Abbott), and tick “send email” to mail the result. The console refreshes about 2 minutes after the run finishes.

Add a competitor: Edit targets, copy an existing block, change the name and searches, commit.

High-signal items mention keywords like FDA, clearance, launch, acquisition, CLIA or reimbursement (editable in competitors.yaml).

Shortcuts: / search · Esc clear.

Only headlines and short snippets from public sources are stored; follow links for full content.
