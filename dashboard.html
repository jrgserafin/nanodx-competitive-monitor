What runs automatically

  • Weekdays ~7am ET — every source is checked, the point-of-care space is scanned for new companies and the daily digest is emailed.
  • Three more checks each weekday — instant alert emails for FDA decisions, major SEC filings, launches, recalls and deals.
  • Mondays — weekly review and refreshed company profiles.
  • Run a lookup refreshes everything on demand in the background (usually 3–8 minutes) — keep working; the page updates itself when the new data lands. The first time, it asks for a GitHub key that stays in your browser ().
  • Even without a lookup, an open dashboard checks for new data every few minutes and refreshes in place.

Edit the watchlist in competitors.yaml (edit on GitHub). Only public headlines and short snippets are stored. AI briefs and strategy are emailed only and never published here.

  1. Open GitHub → new fine-grained token.
  2. Repository access: Only select repositories → this repo.
  3. Permissions → Repository → Actions: Read and write. Nothing else.
