What runs: every weekday morning a GitHub Action checks Google News, competitor web pages, RSS feeds, FDA 510(k)/PMA decisions, ClinicalTrials.gov and PubMed for each competitor in competitors.yaml. New items are saved here and emailed as a digest.

Look something up now: click Run a lookup now → Run workflow. Leave “only” blank for everyone, or type a name (e.g. Abbott). Tick “send email” to mail the result. The dashboard refreshes about 2 minutes after the run finishes.

Add a competitor: click Edit competitors, copy an existing block, change the name and searches, and commit.

High-signal items mention keywords like FDA, clearance, launch, acquisition, CLIA or reimbursement (editable in competitors.yaml).

Only headlines and short snippets from public sources are stored; follow links for full content.
